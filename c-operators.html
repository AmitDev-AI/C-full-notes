C Operators

Operators are symbols that perform operations on values. C groups them into arithmetic, assignment, comparison, logical, bitwise and a few special ones.

Arithmetic operators

OperatorNameExample (a = 10, b = 3)Result
+Additiona + b13
-Subtractiona - b7
*Multiplicationa * b30
/Divisiona / b3 (integer division)
%Modulus (remainder)a % b1
 
#include <stdio.h>

int main(void) {
    int a = 10, b = 3;

    printf("%d + %d = %d\n", a, b, a + b);
    printf("%d - %d = %d\n", a, b, a - b);
    printf("%d * %d = %d\n", a, b, a * b);
    printf("%d / %d = %d\n", a, b, a / b);
    printf("%d %% %d = %d\n", a, b, a % b);
    return 0;
}
Output
10 + 3 = 13
10 - 3 = 7
10 * 3 = 30
10 / 3 = 3
10 % 3 = 1

Integer division truncates. 7 / 2 is 3, not 3.5. Use a floating-point type: 7.0 / 2 or (double)7 / 2. The % operator works only with integers.

Increment and decrement

++ adds one; -- subtracts one. Their position matters:

int i = 5;

printf("%d\n", i++);   // prints 5, then i becomes 6 (postfix)
printf("%d\n", i);     // 6

printf("%d\n", ++i);   // i becomes 7, then prints 7 (prefix)
printf("%d\n", i--);   // prints 7, then i becomes 6
printf("%d\n", --i);   // i becomes 5, then prints 5
Output
5
6
7
7
5

Note: avoid modifying the same variable more than once in a single expression, as in i = i++ + ++i. That is undefined behaviour.

Comparison operators

Comparison operators return 1 for true and 0 for false.

Do not confuse = with ==. if (x = 5) assigns 5 and is always true. if (x == 5) compares. Compile with -Wall to catch this.

Logical operators

OperatorNameTrue when
&&ANDBoth sides are true
||ORAt least one side is true
!NOTThe value is false (0)
 
int age = 20;
int has_id = 1;

if (age >= 18 && has_id) {
    printf("Entry allowed\n");
}

if (age < 13 || age > 65) {
    printf("Discount\n");
}

if (!has_id) {
    printf("No ID\n");
}

&& and || short-circuit: the right side is not evaluated if the result is already known.

int *p = NULL;

// Safe: the second part is only evaluated if p is not NULL
if (p != NULL && *p == 10) {
    printf("value is 10\n");
}

Bitwise operators

These work on individual bits of integers. They are common in systems programming, flags and embedded code.

OperatorNameExample (a = 6, b = 3)Result
&Bitwise ANDa & b2
|Bitwise ORa | b7
^Bitwise XORa ^ b5
~Bitwise NOT~a-7
<<Shift lefta << 112
>>Shift righta >> 13
 
#include <stdio.h>

int main(void) {
    int a = 6;   // 0110
    int b = 3;   // 0011

    printf("a & b  = %d\n", a & b);    // 0010 = 2
    printf("a | b  = %d\n", a | b);    // 0111 = 7
    printf("a ^ b  = %d\n", a ^ b);    // 0101 = 5
    printf("a << 1 = %d\n", a << 1);   // 1100 = 12
    printf("a >> 1 = %d\n", a >> 1);   // 0011 = 3
    return 0;
}
Output
a & b  = 2
a | b  = 7
a ^ b  = 5
a << 1 = 12
a >> 1 = 3

Shifting left by n multiplies by 2n; shifting right divides by 2n (for non-negative values).

The ternary operator

int age = 20;
const char *status = (age >= 18) ? "adult" : "minor";
printf("%s\n", status);   // adult

// Equivalent if/else:
// if (age >= 18) status = "adult";
// else status = "minor";

Operators with higher precedence bind first. When in doubt, add parentheses — they cost nothing and prevent bugs.

int result = 2 + 3 * 4;        // 14, not 20
int fixed  = (2 + 3) * 4;      // 20

int x = 1, y = 2;
int z = x + y << 1;            // (1 + 2) << 1 = 6
int w = x + (y << 1);          // 1 + 4 = 5

Common mistakes

  • = instead of == in conditions.
  • Forgetting that / between integers truncates.
  • Using % with floats (not allowed).
  • Dividing by zero (undefined behaviour; the program may crash).
  • Assuming & means logical AND — it is bitwise AND.
  • Confusing a & b == c with (a & b) == c — equality binds tighter.

Exercises

  1. Ask for two integers and print their sum, difference, product, quotient and remainder.
  2. Use a ternary operator to print "even" or "odd" for a number.
  3. Set bits 0 and 3 of an integer using |=, then print the result in hex.
  4. Predict the result of 5 + 2 * 3 - 4 / 2 before running it.
