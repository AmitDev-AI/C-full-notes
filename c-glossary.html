C Glossary

Short, practical definitions of the words you meet while learning C. Use the filter to find a term instantly.

ABCDEFGHIKLMNOPRSTUVW

A

Address

A number that identifies a byte in memory. The & operator obtains the address of a variable; a pointer stores one.

Argument

A value passed to a function at the call site. The matching variable inside the function is the parameter. The words are often used interchangeably.

Array

A fixed-size block of consecutive elements of one type. Indexes start at 0. An array name decays to a pointer to its first element when passed to a function.

ASCII

A character encoding that maps 0–127 to letters, digits, punctuation and control codes. For example 'A' is 65 and '0' is 48.

Assembly

Low-level human-readable machine instructions. C compilers translate source code to assembly or directly to object code.

auto

The default storage class for local variables. In modern C, auto is almost never written explicitly.

B

Binary

Base-2 notation using only 0 and 1. One binary digit is a bit; eight bits make a byte.

Bit

The smallest unit of data: 0 or 1. Bitwise operators work directly on individual bits.

Bitwise operator

& AND, | OR, ^ XOR, ~ NOT, and shifts << / >>. They operate on the binary representation of integers.

Block

A group of statements inside braces { }. A block introduces a new scope.

Buffer

A region of memory used to hold data temporarily, commonly an array receiving input or file contents.

Buffer overflow

Writing past the end of an array or buffer. It corrupts neighbouring memory and is a classic security bug. Use bounded functions and check lengths.

Byte

Eight bits. sizeof(char) is always 1 byte in C.

C

Call stack

The runtime structure that holds one stack frame per active function call, including parameters, locals and the return address.

Cast

Explicit conversion between types, written (double)n or (int)3.9. Casting does not change the original variable.

char

The smallest integer type, usually one byte. It stores a character code or a small integer. A string is an array of char ending in '\0'.

Compiler

A program that translates C source code into object code, then links it into an executable. GCC, Clang and MSVC are common C compilers.

const

A qualifier promising that a value will not be modified through that name. const int *p means the pointed-to value is read-only; int *const p means the pointer itself is fixed.

Constant

A value that cannot change, such as 42, 'A', 3.14, or a name defined with #define / const.

D

Dangling pointer

A pointer that still holds the address of memory that has been freed or gone out of scope. Using it is undefined behaviour — set pointers to NULL after free.

Data type

A category that determines the size, representation and allowed operations of a value: int, double, char, pointers, structs and so on.

Declaration

Tells the compiler that a name exists and what type it has, without necessarily allocating storage. A definition creates it.

Dereference

Accessing the value a pointer points to with *p. Dereferencing NULL or an invalid pointer crashes the program.

Directive

A line beginning with # handled by the preprocessor, such as #include, #define and #if.

double

A double-precision floating-point type, usually 8 bytes and about 15 significant decimal digits.

E

enum

A type whose values are named integer constants: enum Color { RED, GREEN, BLUE };. The names are easier to read than raw numbers.

Escape sequence

A backslash combination representing a special character: \n newline, \t tab, \\ backslash, \0 null.

Expression

A combination of values, variables, operators and function calls that produces a value, such as a + b * 2.

F

File pointer

A FILE * returned by fopen and used with fread, fprintf, fclose and related functions.

float

A single-precision floating-point type, usually 4 bytes and about 6 significant digits. Use double unless memory is tight.

Function

A named, reusable block of code with a return type and optional parameters. Every C program starts at main.

Function pointer

A pointer that stores the address of a function, allowing callbacks and dispatch tables: int (*op)(int, int) = add;.

G

Garbage value

An unpredictable value in an uninitialised variable. Local variables are not automatically zeroed — initialise them.

Global variable

A variable declared outside all functions. It is visible from its declaration to the end of the file and lives for the whole program.

H

Header

A .h file containing declarations, macros and type definitions, included with #include.

Heap

The region used for dynamic allocation with malloc, calloc and realloc. You manage its lifetime with free.

Hexadecimal

Base-16 notation using 0–9 and A–F, written with a 0x prefix: 0xFF is 255. Common for memory addresses and bit masks.

I

Identifier

A name for a variable, function, type or label. It must begin with a letter or underscore and contain only letters, digits and underscores.

Include guard

#ifndef NAME_H / #define NAME_H / #endif around a header, preventing it from being included twice.

Initialisation

Giving a variable its first value at the point of definition: int n = 0;. Distinct from later assignment.

Integer

A whole number with no fractional part, such as int, long or unsigned short.

Interpreter

A program that executes source code directly instead of producing a native executable. The Try It Editor uses a small C interpreter (PicoC) compiled to WebAssembly.

K

Keyword

A word reserved by the language, such as int, return, while or struct. You cannot use it as an identifier.

L

Library

A collection of compiled functions and declarations that can be linked into your program, such as the C standard library or a maths library.

Linker

The tool that combines object files and libraries into an executable, resolving references between them.

Literal

A value written directly in source code: 42, 3.14, 'x', "hello".

Local variable

A variable declared inside a block or function. It exists only while that block executes.

Loop

A construct that repeats statements: for, while or do...while.

Lvalue

An expression that refers to a storage location and can appear on the left of an assignment, such as a variable or *p.

M

Macro

A preprocessor name replaced textually before compilation, defined with #define. Parenthesise macro parameters carefully.

main

The entry point of a C program. It returns an int status to the operating system; 0 means success.

Memory leak

Memory that was allocated but never freed, so the program keeps consuming memory until it exits.

N

Null pointer

A pointer with the value NULL, meaning it points to nothing. Check before dereferencing.

Null terminator

The '\0' character that marks the end of a C string. Functions such as printf("%s") and strlen rely on it.

O

Operand

A value or expression that an operator acts on. In a + b, both a and b are operands.

Operator

A symbol that performs an operation: arithmetic, comparison, logic, assignment, bitwise or member access.

Overflow

When a value is too large for its type. Signed integer overflow is undefined behaviour; unsigned arithmetic wraps modulo 2n.

P

Parameter

A variable declared in a function definition that receives an argument from the caller.

Pointer

A variable that holds a memory address. Its type says what kind of value lives at that address. Declared with int *p.

Preprocessor

The first translation phase. It handles #include, #define and conditional compilation before the compiler sees the code.

Prototype

A function declaration that gives the name, return type and parameter types, allowing calls before the definition appears.

R

Recursion

A function calling itself. Every recursive function needs a base case that stops the recursion, or the stack will overflow.

Return value

The value a function sends back to its caller with return. A function returning void returns no value.

S

Scope

The part of a program where a name is visible. Block scope ends at }; file scope lasts to the end of the translation unit.

Segmentation fault

A crash caused by accessing memory the process is not allowed to touch — often a NULL or wild pointer, or an out-of-bounds access.

Signed

An integer type that can hold negative and positive values. The default for int is signed.

Stack

The region that stores function call frames and local variables. It grows and shrinks automatically; large local arrays can overflow it.

Statement

A complete instruction, usually ending in a semicolon: a declaration, assignment, call, loop or jump.

static

At file scope, gives a name internal linkage (private to the file). Inside a function, gives a local variable a lifetime for the whole program.

String

A sequence of characters ending in '\0', stored in a char array. There is no separate string type in C.

struct

A composite type grouping named members, possibly of different types, into one object.

Syntax

The grammar rules of the language. A syntax error means the compiler cannot parse the code.

T

Token

The smallest lexical unit: a keyword, identifier, literal, operator or punctuation mark.

typedef

Creates an alias for a type: typedef unsigned long ulong;. It does not create a new type.

U

Undefined behaviour

Code the C standard does not define — for example signed overflow, out-of-bounds access or double free. The compiler may do anything; the program is not reliable.

union

A type whose members share the same memory. Only one member holds a meaningful value at a time. Useful for tagged variants and low-level representations.

unsigned

An integer type that cannot be negative. Unsigned arithmetic wraps around instead of overflowing.

V

Variable

A named storage location with a type. Its value can change during execution.

void

“No type”: a function returning void returns nothing; void * is a generic object pointer that converts to any object pointer type.

volatile

A qualifier telling the compiler that a value may change at any time, so it must not cache or optimise away accesses. Used for hardware registers and signal flags, not for thread synchronisation.

W

Warning

A diagnostic that is probably a mistake but still valid C. Compile with -Wall -Wextra and fix warnings before they become bugs.
