C User Input

Programs read keyboard input from standard input (stdin). The two main tools are scanf for formatted values and fgets for lines of text.

Reading a number with scanf

scanf needs the address of the variable, so you write &age, not age.

#include <stdio.h>

int main(void) {
    int age;

    printf("Enter your age: ");
    if (scanf("%d", &age) == 1) {
        printf("You are %d years old.\n", age);
    } else {
        printf("That was not a number.\n");
    }

    return 0;
}
Input
25
Output
Enter your age: You are 25 years old.

scanf conversion specifiers

TypeSpecifierExample
int%dscanf("%d", &n);
unsigned%uscanf("%u", &n);
long%ldscanf("%ld", &n);
long long%lldscanf("%lld", &n);
float%fscanf("%f", &f);
double%lfscanf("%lf", &d);
char%cscanf(" %c", &c); (note the space)
string%sscanf("%49s", word); (no &)

Remember: use %f when printing a float or double with printf, but %lf when reading a double with scanf.

Reading several values

#include <stdio.h>

int main(void) {
    int a, b;

    printf("Enter two integers: ");
    if (scanf("%d %d", &a, &b) == 2) {
        printf("sum = %d\n", a + b);
    } else {
        printf("Invalid input\n");
    }
    return 0;
}
Input
12 30
Output
Enter two integers: sum = 42

scanf returns a count

The return value is the number of items successfully read, or EOF on failure. Always check it — otherwise bad input leaves the variable unchanged and your program misbehaves.

int n;
int result = scanf("%d", &n);

if (result == 1) {
    printf("Read %d\n", n);
} else if (result == EOF) {
    printf("End of input\n");
} else {
    printf("Not a number\n");
}

Reading strings safely with fgets

scanf("%s") stops at whitespace and can overflow the buffer. fgets reads a whole line and takes a size limit.

#include <stdio.h>
#include <string.h>

int main(void) {
    char name[100];

    printf("Enter your full name: ");
    if (fgets(name, sizeof(name), stdin) != NULL) {
        size_t len = strlen(name);
        if (len > 0 && name[len - 1] == '\n') {
            name[len - 1] = '\0';      // strip newline
        }
        printf("Hello, %s!\n", name);
    }
    return 0;
}
Input
Amit Mahanta
Output
Enter your full name: Hello, Amit Mahanta!

fgets returns NULL at end-of-file or on error. If the line is longer than the buffer, the rest stays in the input stream.

Reading one character with getchar

#include <stdio.h>

int main(void) {
    printf("Press Enter to continue...");
    int c;
    do {
        c = getchar();
    } while (c != '\n' && c != EOF);

    printf("Continuing!\n");
    return 0;
}

getchar returns an int so it can represent EOF (−1) as well as all byte values. Store its result in an int, not a char.

The leftover-newline problem

After scanf("%d"), the newline stays in the input buffer. A following %c or fgets may read it immediately.

int age;
char initial;

printf("Age: ");
scanf("%d", &age);        // leaves '\n' in the buffer

printf("Initial: ");
scanf(" %c", &initial);   // the leading space skips whitespace

// Alternative: discard the rest of the line
// int c;
// while ((c = getchar()) != '\n' && c != EOF) { }

The space in " %c" is not decoration: it tells scanf to skip whitespace before reading the character.

Parsing a whole line with sscanf

#include <stdio.h>

int main(void) {
    char line[] = "Amit 25 5.9";
    char name[20];
    int age;
    double height;

    if (sscanf(line, "%19s %d %lf", name, &age, &height) == 3) {
        printf("%s is %d years old and %.1f ft tall.\n", name, age, height);
    }
    return 0;
}
Output
Amit is 25 years old and 5.9 ft tall.

Reading command-line arguments

Arguments passed after the program name arrive through main's parameters.

#include <stdio.h>

int main(int argc, char *argv[]) {
    printf("Program: %s\n", argv[0]);

    for (int i = 1; i < argc; i++) {
        printf("argument %d: %s\n", i, argv[i]);
    }
    return 0;
}
Command
./args hello world
Output
Program: ./args
argument 1: hello
argument 2: world

Input checklist

  • Check the return value of scanf.
  • Put & before numeric variables, but not before strings in scanf("%s").
  • Use a width limit with %s: %49s for a 50-byte array.
  • Use fgets for text that may contain spaces.
  • Strip the newline left by fgets.
  • Clear the input buffer when mixing scanf and character reads.
  • Never use gets — it was removed from C11 because it cannot be made safe.

Exercises

  1. Read two numbers and print their sum, product and average.
  2. Read a name with spaces using fgets and greet the user.
  3. Ask for an age repeatedly until a valid positive number is entered.
  4. Read a line like "item 3 19.99" with sscanf and print a formatted receipt line.
