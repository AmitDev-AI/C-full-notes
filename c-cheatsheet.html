C Cheat Sheet

The whole language on one page: syntax, types, operators, pointers, memory, files and the functions you will actually use. Keep it open while you practise — or print it.

Program skeleton

#include <stdio.h>   /* declarations of printf, scanf, FILE ... */

#define MAX 100       /* preprocessor constant */

int helper(int x);    /* function prototype */

int main(void) {      /* entry point; returns int to the OS */
    int n = 42;
    printf("n = %d\n", n);
    return 0;         /* 0 means success */
}

Compile: gcc main.c -o main · Run: ./main (Windows: main.exe). Add -Wall -Wextra -std=c17 for useful warnings.

Functions and storage

int add(int a, int b);              /* prototype */

int add(int a, int b) {             /* definition */
    return a + b;
}

void greet(void) {                  /* no parameters, no return */
    puts("Hello");
}

int main(void) {
    printf("%d\n", add(2, 3));
    greet();
    return 0;
}
KeywordMeaning
staticAt file scope: visible only in this file. Inside a function: keeps its value between calls.
externDeclares something defined in another file.
constValue cannot be changed through this name.
inlineHint to expand the function at the call site.
registerHistoric hint; rarely useful today.
volatileThe value may change outside the program's control (hardware, signals). Prevents some optimisations.

Pointers and arrays

int n = 42;
int *p = &n;        /* p holds the address of n */
printf("%d\n", *p); /* dereference: 42 */
*p = 99;            /* n is now 99 */

int a[5] = {10, 20, 30, 40, 50};
int *q = a;         /* array name decays to &a[0] */
printf("%d\n", q[2]);      /* 30 */
printf("%d\n", *(q + 2));  /* 30 — same thing */

int matrix[2][3];   /* 2 rows, 3 columns */
matrix[1][2] = 7;
  • a[i] is exactly *(a + i).
  • Passing an array to a function passes a pointer; the function cannot know its length unless you pass it.
  • NULL means “points to nothing”. Always check a pointer before dereferencing it.
  • Pointer arithmetic moves in units of the pointed-to type: p + 1 skips sizeof(*p) bytes.

Strings

#include <string.h>

char name[32] = "Ada";        /* 31 characters + '\0' */
char copy[32];

strlen(name)                  /* 3 (does not count '\0') */
strcpy(copy, name);           /* unsafe without a size check */
strncpy(copy, name, 31);      /* bounded copy */
strcat(copy, " Lovelace");    /* append */
strcmp(a, b)                  /* 0 if equal, <0 or >0 otherwise */
strchr(name, 'd')             /* pointer to first 'd', or NULL */
strstr(text, "love")          /* pointer to substring, or NULL */
sprintf(buf, "%d", 42);       /* format into a string */
snprintf(buf, sizeof(buf), "%d", 42);  /* safer */

Structs, unions, enums, typedef

struct Point {
    int x;
    int y;
};

struct Point p = {3, 4};      /* initialise in order */
p.x = 10;
struct Point *ptr = &p;
printf("%d\n", ptr->y);       /* arrow: member through pointer */

typedef struct {
    char name[40];
    int age;
} Person;                     /* Person is now a type name */

enum Color { RED, GREEN = 5, BLUE };   /* 0, 5, 6 */

union Number {
    int i;
    float f;
};                            /* members share the same memory */

Memory management

FunctionPurpose
malloc(size)Allocate uninitialised bytes; returns NULL on failure.
calloc(n, size)Allocate n zeroed elements.
realloc(p, size)Resize an allocation; may move it.
free(p)Release memory; p must come from malloc/calloc/realloc.
int *a = malloc(10 * sizeof *a);
if (a == NULL) {
    fprintf(stderr, "out of memory\n");
    return 1;
}
a[0] = 1;
free(a);
a = NULL;          /* avoid a dangling pointer */

Every malloc needs exactly one matching free. Never free the same block twice, and never use memory after freeing it.

File I/O

#include <stdio.h>

FILE *fp = fopen("data.txt", "w");
if (fp == NULL) {
    perror("data.txt");
    return 1;
}
fprintf(fp, "score = %d\n", 42);
fclose(fp);

fp = fopen("data.txt", "r");
char line[128];
while (fgets(line, sizeof line, fp) != NULL) {
    fputs(line, stdout);
}
fclose(fp);
ModeMeaning
"r"Read; fails if the file does not exist.
"w"Write; creates or truncates.
"a"Append; creates if needed.
"r+" / "w+" / "a+"Read and write variants.
"rb" / "wb"Binary mode (important on Windows).

Common beginner errors

SymptomLikely cause
expected ';' before ...Missing semicolon, brace or parenthesis on the previous line.
undefined reference to 'foo'Function declared but not defined, or the object file/library was not linked.
implicit declaration of functionMissing #include or prototype.
Program crashes with a segmentation faultDereferencing NULL/uninitialised pointer, out-of-bounds array access, or using freed memory.
scanf seems to skip inputUse " %c" (leading space) after reading a number, or read whole lines with fgets.
Infinite loopLoop variable never changes, or the condition can never become false.
Garbage string outputMissing '\0', buffer overflow, or returning a pointer to a local array.
Wrong integer division5 / 2 is 2; use 5 / 2.0 or cast to double.
