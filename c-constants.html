C Constants

A constant is a value that must not change while the program runs. C gives you three ways to express one: literal values, const variables, and #define macros.

Literal constants

A literal is a value written directly in the source code.

42          // integer literal (decimal)
0x2A        // hexadecimal 42
052         // octal 42
0b101010    // binary 42 (C23 / GCC extension)

3.14        // double literal
3.14f       // float literal
3.14L       // long double literal

'A'         // char literal
"Hello"     // string literal

const variables

Adding const makes a variable read-only. The compiler rejects any attempt to assign to it.

#include <stdio.h>

int main(void) {
    const double PI = 3.141592653589793;
    const int MAX_USERS = 100;

    printf("PI = %.5f\n", PI);
    printf("Max users = %d\n", MAX_USERS);

    // PI = 3.14;   // error: assignment of read-only variable
    return 0;
}
Output
PI = 3.14159
Max users = 100

const variables have a type, so the compiler can check them and a debugger can see them. They also follow normal scope rules.

const pointers

The position of const changes its meaning:

int value = 10;

const int *p1 = &value;        // pointer to const int: *p1 cannot change
int * const p2 = &value;       // const pointer: p2 cannot change
const int * const p3 = &value; // neither can change

*p1 = 20;      // error
p1 = NULL;     // OK: the pointer itself can move
*p2 = 20;      // OK: the value can change
p2 = NULL;     // error

Read declarations right-to-left: "p1 is a pointer to a const int", "p2 is a const pointer to int".

#define macros

The preprocessor replaces text before the compiler sees it. A macro is not a variable — it has no type, no scope and no memory.

#include <stdio.h>

#define PI 3.141592653589793
#define MAX_USERS 100
#define NEWLINE '\n'

int main(void) {
    printf("PI = %.5f\n", PI);
    printf("Max users = %d\n", MAX_USERS);
    putchar(NEWLINE);
    return 0;
}
Output
PI = 3.14159
Max users = 100

Macros with arguments

#define SQUARE(x) ((x) * (x))
#define MAX(a, b) ((a) > (b) ? (a) : (b))

printf("%d\n", SQUARE(5));     // 25
printf("%d\n", MAX(3, 9));     // 9

The extra parentheses are essential. Without them, SQUARE(2 + 3) would expand to 2 + 3 * 2 + 3 and produce 11 instead of 25.

// Dangerous macro: arguments evaluated twice
#define BAD_MAX(a, b) ((a) > (b) ? (a) : (b))

int i = 0;
int m = BAD_MAX(i++, 10);   // i may be incremented twice

// Safer: use an inline function
static inline int max_int(int a, int b) {
    return a > b ? a : b;
}

Tip: prefer const (or enum) over object-like macros. Use macros for include guards and conditional compilation, where the preprocessor is actually needed.

enum constants

An enumeration creates a set of named integer constants. It is the clean way to express a fixed list of values.

#include <stdio.h>

enum Color { RED, GREEN, BLUE };          // 0, 1, 2

int main(void) {
    enum Color c = GREEN;
    printf("%d\n", c);                    // 1

    if (c == GREEN) {
        printf("The colour is green\n");
    }
    return 0;
}
Output
1
The colour is green

Common mistakes

  • Missing parentheses in macros — #define HALF(x) x/2 breaks for expressions.
  • Semicolon after a macro — #define MAX 100; puts a semicolon into every expansion. Do not add one.
  • Trying to modify a const — the compiler stops you; casting away const and writing is undefined behaviour.
  • Assuming const means compile-time constant — in C it means read-only. For array sizes, use an enum constant, a macro, or (C99+) a variable-length array.

  2. Write a SQUARE macro and test it with SQUARE(2 + 3).
  3. Create an enum for the days of the week and print Wednesday's numeric value.
