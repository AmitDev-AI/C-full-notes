C If...Else

Conditions let a program choose between different paths. In C, 0 is false and any non-zero value is true.

The if statement

Run a block only when a condition is true.

#include <stdio.h>

int main(void) {
    int age = 20;

    if (age >= 18) {
        printf("You are an adult.\n");
    }

    return 0;
}
Output
You are an adult.

The condition must be in parentheses. The braces are optional for a single statement, but always using them prevents mistakes.

if...else

Provide a second path when the condition is false.

#include <stdio.h>

int main(void) {
    int age = 15;

    if (age >= 18) {
        printf("You can vote.\n");
    } else {
        printf("You cannot vote yet.\n");
    }

    return 0;
}
Output
You cannot vote yet.

if...else if...else

Test several conditions in order. The first true branch wins; the rest are skipped.

#include <stdio.h>

int main(void) {
    int score = 82;

    if (score >= 90) {
        printf("Grade A\n");
    } else if (score >= 80) {
        printf("Grade B\n");
    } else if (score >= 70) {
        printf("Grade C\n");
    } else if (score >= 60) {
        printf("Grade D\n");
    } else {
        printf("Grade F\n");
    }

    return 0;
}
Output
Grade B

Order matters. If you tested score >= 60 first, every score above 60 would get a D.

Nested conditions

An if can contain another if. Keep nesting shallow; deep nesting is hard to read.

int logged_in = 1;
int is_admin = 0;

if (logged_in) {
    if (is_admin) {
        printf("Admin panel\n");
    } else {
        printf("User dashboard\n");
    }
} else {
    printf("Please log in\n");
}

A flatter version with && is often clearer:

if (logged_in && is_admin) {
    printf("Admin panel\n");
} else if (logged_in) {
    printf("User dashboard\n");
} else {
    printf("Please log in\n");
}

The ternary operator

A compact one-line choice: condition ? value_if_true : value_if_false.

#include <stdio.h>

int main(void) {
    int number = 7;

    const char *type = (number % 2 == 0) ? "even" : "odd";
    printf("%d is %s\n", number, type);

    int a = 10, b = 20;
    int max = (a > b) ? a : b;
    printf("max = %d\n", max);
    return 0;
}
Output
7 is odd
max = 20

Use the ternary form for short, simple choices. For anything longer, use if...else.

Truthiness in C

if (1)      { /* runs */ }
if (-5)     { /* runs: any non-zero is true */ }
if (0)      { /* does not run */ }
if ('A')    { /* runs: 'A' is 65 */ }
if (NULL)   { /* does not run: NULL is 0 */ }

int count = 0;
if (count)  { /* does not run */ }
if (!count) { /* runs */ }

if (x == 1, 2)Comma operator; only the last value counts.if (x == 1 || x == 2)

Complete example: a simple calculator check

#include <stdio.h>

int main(void) {
    char op = '+';
    int a = 12, b = 4;
    int result = 0;

    if (op == '+') {
        result = a + b;
    } else if (op == '-') {
        result = a - b;
    } else if (op == '*') {
        result = a * b;
    } else if (op == '/') {
        if (b != 0) {
            result = a / b;
        } else {
            printf("Cannot divide by zero\n");
            return 1;
        }
    } else {
        printf("Unknown operator\n");
        return 1;
    }

    printf("%d %c %d = %d\n", a, op, b, result);
    return 0;
}
Output
12 + 4 = 16

Tip: when you have many fixed options to compare against one value, a switch is usually cleaner than a long if...else if chain.
