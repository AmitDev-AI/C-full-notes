C Reference

A quick lookup for the things you reach for while writing C: keywords, types, format specifiers, headers and library functions.

Keywords

C89/C90 has 32 keywords. C99 added five, C11 added seven, and C23 added several more.

CategoryKeywords
Typeschar double float int long short signed unsigned void _Bool
Storage / qualifiersauto const extern register static volatile inline restrict _Atomic _Thread_local
Control flowbreak case continue default do else for goto if return switch while
Aggregate typesenum struct union typedef
Operatorssizeof _Alignof _Generic
Other_Static_assert _Noreturn _Complex _Imaginary

All keywords are lowercase and reserved. You cannot use them as identifiers.

Command-line arguments and exit codes

int main(int argc, char *argv[]) {
    // argv[0] is the program name
    // argv[1] .. argv[argc - 1] are the arguments
    // argv[argc] is NULL
    return 0;    // 0 = success, non-zero = failure
}
