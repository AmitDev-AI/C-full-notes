C Pointers

A pointer is a variable that stores the memory address of another value. Pointers are what make C powerful — and what make it dangerous.

Addresses and the & operator

Every variable lives at some address. The unary & operator ("address of") gives you that address.

#include <stdio.h>

int main(void) {
    int age = 25;

    printf("age = %d\n", age);
    printf("address of age = %p\n", (void *)&age);
    return 0;
}
Output
age = 25
address of age = 0x7ffee3b6a8ac

The exact address changes on every run. Addresses are printed with %p.

Declaring a pointer

int *p;        // pointer to int
double *d;     // pointer to double
char *s;       // pointer to char (often a string)
void *v;       // generic pointer; can hold any address

int x = 10;
int *ptr = &x; // ptr now holds the address of x

The * in a declaration means "pointer to". The type matters: it tells the compiler how many bytes to read when dereferencing and how far to step in pointer arithmetic.

Dereferencing with *

The unary * operator ("dereference") accesses the value at the address.

#include <stdio.h>

int main(void) {
    int value = 42;
    int *p = &value;

    printf("value      = %d\n", value);
    printf("*p         = %d\n", *p);      // read through pointer
    printf("&value     = %p\n", (void *)&value);
    printf("p          = %p\n", (void *)p);

    *p = 100;                            // write through pointer
    printf("value now  = %d\n", value);

    return 0;
}
Output
value      = 42
*p         = 42
&value     = 0x7ffc1d2a3b4c
p          = 0x7ffc1d2a3b4c
value now  = 100

Changing *p changes value because both refer to the same memory.

NULL pointers

A pointer that does not point anywhere should be set to NULL (defined in <stddef.h>). Check before dereferencing.

#include <stdio.h>
#include <stddef.h>

int main(void) {
    int *p = NULL;

    if (p != NULL) {
        printf("%d\n", *p);
    } else {
        printf("p does not point anywhere\n");
    }
    return 0;
}
Output
p does not point anywhere

Never dereference NULL. *p when p == NULL usually crashes the program. It is also good practice to set a pointer to NULL after freeing its memory.

Pointers and functions

Pass an address to let a function modify the caller's variable. This is how scanf works.

#include <stdio.h>

void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

void increment(int *n) {
    (*n)++;
}

int main(void) {
    int x = 5, y = 10;

    swap(&x, &y);
    printf("x = %d, y = %d\n", x, y);   // x = 10, y = 5

    increment(&x);                     // x = 11
    printf("x = %d\n", x);
    return 0;
}
Output
x = 10, y = 5
x = 11

Note (*n)++: the parentheses are required. *n++ means "increment the pointer, then dereference".

Pointers and arrays

An array name decays to a pointer to its first element. a[i] is defined as *(a + i).

#include <stdio.h>

int main(void) {
    int a[5] = {10, 20, 30, 40, 50};
    int *p = a;              // same as &a[0]

    printf("%d\n", a[0]);    // 10
    printf("%d\n", *p);      // 10
    printf("%d\n", p[2]);    // 30
    printf("%d\n", *(a + 3));// 40

    for (int i = 0; i < 5; i++) {
        printf("%d ", *(p + i));
    }
    printf("\n");
    return 0;
}
Output
10
10
30
40
10 20 30 40 50

Pointer arithmetic

Adding 1 to a pointer moves it to the next element — not the next byte. The step size is the size of the pointed-to type.

int a[4] = {10, 20, 30, 40};
int *p = a;

printf("%d\n", *p);       // 10
p++;
printf("%d\n", *p);       // 20
p += 2;
printf("%d\n", *p);       // 40

int distance = (int)(&a[3] - &a[0]);   // 3 elements
printf("%d\n", distance);

Subtracting two pointers into the same array gives the number of elements between them. Adding two pointers is meaningless and not allowed.

Pointers to structures

Use -> to access a member through a pointer. It is shorthand for (*ptr).member.

#include <stdio.h>

struct Point {
    int x;
    int y;
};

int main(void) {
    struct Point p = {10, 20};
    struct Point *ptr = &p;

    printf("x = %d\n", ptr->x);
    printf("y = %d\n", ptr->y);

    ptr->x = 99;
    printf("p.x = %d\n", p.x);
    return 0;
}
Output
x = 10
y = 20
p.x = 99

Pointers to pointers

int value = 7;
int *p = &value;      // pointer to int
int **pp = &p;        // pointer to pointer to int

printf("%d\n", **pp);   // 7
**pp = 8;
printf("%d\n", value);  // 8

Function pointers

Functions also have addresses. A function pointer can choose behaviour at run time.

#include <stdio.h>

int add(int a, int b) { return a + b; }
int sub(int a, int b) { return a - b; }

int main(void) {
    int (*operation)(int, int) = add;

    printf("%d\n", operation(10, 3));   // 13
    operation = sub;
    printf("%d\n", operation(10, 3));   // 7
    return 0;
}
Output
13
7

const and pointers

int value = 10;

const int *p1 = &value;         // cannot change *p1
int * const p2 = &value;        // cannot change p2
const int * const p3 = &value;  // cannot change either

*p1 = 20;      // error
p1 = NULL;     // allowed
p2 = NULL;     // error
*p2 = 20;      // allowed

Common pointer bugs

  • Uninitialised pointer — points at a random address. Always initialise to NULL or a real address.
  • Dangling pointer — points at memory that has been freed or gone out of scope.
  • Double free — calling free twice on the same allocation.
  • Wild write — *p = 5 when p was never valid. Silent memory corruption.
  • Pointer type mismatch — reading a double through an int * gives nonsense.
  • Forgetting & — passing an int where an int * is expected.

Tip: compile with -Wall -Wextra and run memory-sensitive code under Valgrind (Linux) or AddressSanitizer (gcc -fsanitize=address). They catch the bugs that "seem to work".

A mental model

Think of memory as a street of numbered houses. A variable is a house containing a value. A pointer is a piece of paper with a house number written on it. Dereferencing means walking to that house and reading or writing what is inside.
