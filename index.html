How this site works

Every page follows the same pattern: a short explanation, one or more code examples, and notes about the mistakes beginners make. The Try it button opens the built-in editor with that example loaded. Press Run to compile and execute it with PicoC, a small C interpreter compiled to WebAssembly — real output, real input through scanf, and no server involved.

Offline first. This site is a set of plain HTML, CSS, JavaScript and WebAssembly files. There are no third-party scripts, no fonts loaded from the internet and no tracking. Save the folder to a USB drive or open index.html directly in any modern browser. When served over HTTP(S), it can also be installed as a standalone app and cached for offline use.

Built-in study tools

  • Real C execution. The editor runs a C interpreter locally; programs are stopped after 10 seconds if they loop forever.
  • Progress tracking. Mark chapters complete, see the percentage in the sidebar, and solve exercises with saved ticks.
  • Quiz and certificate. Your best quiz score is saved, and the certificate unlocks when all chapters and the quiz are complete.
  • Search and bookmarks. Full-text search over the whole site, plus a personal bookmark list.
  • Dark mode, keyboard shortcuts, print styles. Press ? anywhere to see the shortcuts.

One honest limitation. PicoC supports a practical subset of C89/C99. A few valid standard-C constructs — such as aggregate initialisers for structs, very complex macros and variable-length arrays — may be rejected. For production code and full standard C, use GCC or Clang as described in C Get Started.

Why learn C?

  • It is small and honest. C has around 40 keywords. Once you understand C, very little about it is hidden from you.
  • It teaches how computers work. Pointers, memory layout and manual allocation build a mental model that higher-level languages often hide.
  • It is everywhere. Linux, Windows, Git, SQLite, Python's interpreter, and most embedded firmware are written in C.
  • It is the base for C++, C#, Java and Go. Their syntax and many concepts descend from C.

What you need

A C compiler and a text editor. On Windows, the easiest route is GCC via MSYS2 or Visual Studio Community; on macOS, Xcode Command Line Tools; on Linux, the build-essential / gcc package. The next chapter walks through it.
