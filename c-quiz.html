C Quiz

Fifteen questions covering the whole tutorial. Pick an answer for each, then check your score. Explanations appear after checking.

1. Which header declares printf?

B. printf is part of the standard input/output library in <stdio.h>.

2. Which is a valid definition of the entry point?

C. The standard form returns int. void main is not standard C.

3. What does printf("%d", 7 / 2); print?

A. Integer division truncates the fractional part.

4. Which condition tests whether x equals 5?

B. == compares; = assigns. === does not exist in C.

5. What is the first valid index of an array?

A. C arrays are zero-indexed: valid indices are 0 to length - 1.

6. Which loop always executes its body at least once?

C. do...while checks its condition after running the body.

7. What character marks the end of a C string?

B. A null character '\0' (value 0) terminates every C string.

8. How many bytes does char s[] = "Hi"; occupy?

B. Two visible characters plus the null terminator = 3 bytes.

9. Which operator gives the address of a variable?

D. &x yields the address of x; *p dereferences a pointer.

10. What type does malloc return?

C. malloc returns void *, which converts to any object pointer type. It returns NULL on failure.

11. Which is the correct way to release memory allocated with malloc?

A. free returns the block to the allocator. Setting the pointer to NULL afterwards helps avoid use-after-free.

12. Given struct Point { int x, y; } p, *ptr = &p;, how do you access x through ptr?

C. ptr->x is shorthand for (*ptr).x.

13. What does fopen("data.txt", "r") return if the file does not exist?

B. Read mode fails with NULL; always check before using the stream.

14. What happens if a switch case has no break?

A. Without break, control continues into the following case labels.

15. What is the value of GREEN in enum Color { RED, GREEN, BLUE };?

D. Enumerators start at 0 and increase by one: RED = 0, GREEN = 1, BLUE = 2.
