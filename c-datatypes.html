C Data Types

A data type tells the compiler what kind of value a variable stores and how many bytes to reserve. C has a small set of built-in types plus the ability to build your own from structures, unions and enums.

The basic types

TypeTypical sizeHoldsFormat
char1 byteA single character or small integer%c
int2 or 4 bytesWhole numbers%d
shortusually 2 bytesSmaller whole numbers%hd
long4 or 8 bytesLarger whole numbers%ld
long longat least 8 bytesVery large whole numbers%lld
float4 bytesDecimal numbers, ~7 digits precision%f
double8 bytesDecimal numbers, ~15 digits precision%lf
voidnoneNo value / generic pointer—

Important: the C standard does not fix most sizes. It guarantees only minimum ranges. Use sizeof and <stdint.h> when exact sizes matter.

Example: the basic types

#include <stdio.h>

int main(void) {
    char letter = 'A';
    int count = 42;
    short small = 12;
    long big = 1234567890L;
    long long huge = 9000000000LL;
    float ratio = 0.75f;
    double precise = 3.141592653589793;

    printf("char:        %c\n", letter);
    printf("int:         %d\n", count);
    printf("short:       %hd\n", small);
    printf("long:        %ld\n", big);
    printf("long long:   %lld\n", huge);
    printf("float:       %.2f\n", ratio);
    printf("double:      %.15f\n", precise);
    return 0;
}
Output
char:        A
int:         42
short:       12
long:        1234567890
long long:   9000000000
float:       0.75
double:      3.141592653589793

How big is a type? sizeof

sizeof is an operator that returns the size in bytes. Use %zu to print it.

#include <stdio.h>

int main(void) {
    printf("char      = %zu byte\n", sizeof(char));
    printf("int       = %zu bytes\n", sizeof(int));
    printf("float     = %zu bytes\n", sizeof(float));
    printf("double    = %zu bytes\n", sizeof(double));
    printf("long      = %zu bytes\n", sizeof(long));
    printf("pointer   = %zu bytes\n", sizeof(void *));
    return 0;
}
Output
char      = 1 byte
int       = 4 bytes
float     = 4 bytes
double    = 8 bytes
long      = 8 bytes
pointer   = 8 bytes

On a typical 64-bit system. On 32-bit systems long and pointers are usually 4 bytes.

Ranges and limits.h

#include <stdio.h>
#include <limits.h>

int main(void) {
    printf("char min:  %d\n", CHAR_MIN);
    printf("char max:  %d\n", CHAR_MAX);
    printf("int min:   %d\n", INT_MIN);
    printf("int max:   %d\n", INT_MAX);
    printf("UINT max:  %u\n", UINT_MAX);
    return 0;
}
Output
char min:  -128
char max:  127
int min:   -2147483648
int max:   2147483647
UINT max:  4294967295

Signed and unsigned

Integer types can be signed (default, includes negatives) or unsigned (only zero and positives, with twice the positive range).

int a = -10;
unsigned int b = 10;
unsigned char c = 255;    // range 0..255

printf("%d\n", a);   // -10
printf("%u\n", b);   // 10
printf("%u\n", c);   // 255

c = c + 1;           // wraps around to 0
printf("%u\n", c);

Unsigned overflow wraps modulo 2n; signed overflow is undefined behaviour. Be careful when subtracting unsigned values.

float vs double

float uses 4 bytes and about 7 significant decimal digits. double uses 8 bytes and about 15. Use double for most calculations and float when memory matters (large arrays, graphics, embedded).

#include <stdio.h>

int main(void) {
    float  f = 1.0f / 3.0f;
    double d = 1.0 / 3.0;

    printf("float:  %.10f\n", f);
    printf("double: %.10f\n", d);
    return 0;
}
Output
float:  0.3333333433
double: 0.3333333333

Floating-point numbers are approximations. Do not compare them with ==; compare the difference to a small epsilon instead.

Type conversion and casting

C converts between types automatically when needed (implicit conversion), and you can force a conversion with a cast.

#include <stdio.h>

int main(void) {
    int i = 9;
    int j = 2;

    printf("%d\n", i / j);            // 4  (integer division)
    printf("%f\n", (double)i / j);    // 4.500000
    printf("%d\n", (int)3.99);        // 3  (truncation)

    double d = 7.8;
    int rounded = (int)(d + 0.5);     // 8
    printf("%d\n", rounded);
    return 0;
}
Output
4
4.500000
3
8

Boolean values

C traditionally uses int for truth: 0 is false, any non-zero value is true. C99 added <stdbool.h> with bool, true and false.

#include <stdio.h>
#include <stdbool.h>

int main(void) {
    bool logged_in = true;
    bool finished = false;

    printf("logged_in = %d\n", logged_in);   // 1
    printf("finished  = %d\n", finished);    // 0

    if (logged_in) {
        printf("Welcome!\n");
    }
    return 0;
}
Output
logged_in = 1
finished  = 0
Welcome!

Fixed-width integers (stdint.h)

When the exact number of bits matters — file formats, networking, hardware — use the typedefs from <stdint.h>:

#include <stdint.h>

int8_t   a = -128;        // exactly 8 bits, signed
uint8_t  b = 255;         // exactly 8 bits, unsigned
int16_t  c = -32768;
int32_t  d = 1000000;
uint32_t e = 4000000000u;
int64_t  f = -9000000000LL;
uint64_t g = 18000000000000000000ULL;

Derived and user-defined types

  • Arrays — many values of one type: int scores[10];
  • Pointers — hold addresses: int *p;
  • Functions — have a return type and parameter types.
  • Structures — group different types: struct Point { int x, y; };
  • Unions — members share storage.
  • Enums — named integer constants.
  • typedef — an alias for an existing type.

Tip: choose the simplest type that fits. Use int for ordinary counters, double for maths, size_t for sizes and indexes, and fixed-width types only when the exact width matters.
