C Get Started

To write and run C you need two things: a compiler that turns source code into a program, and a text editor to write it in. This chapter shows the fastest setup on Windows, macOS and Linux.

Step 1 — Install a compiler

Windows: GCC with MSYS2 (recommended)

  1. Download and install MSYS2 from msys2.org.
  2. Open the MSYS2 UCRT64 terminal and run: pacman -S mingw-w64-ucrt-x86_64-gcc
  3. Add C:\msys64\ucrt64\bin to your PATH.
  4. Open a new Command Prompt and check: gcc --version

Windows: Visual Studio

Install Visual Studio Community with the Desktop development with C++ workload. Use the Developer Command Prompt and compile with cl hello.c.

macOS

Open Terminal and run xcode-select --install. This installs Clang, the compiler Apple ships. Verify with clang --version.

Linux (Debian / Ubuntu)

sudo apt update
sudo apt install build-essential

On Fedora use sudo dnf install gcc; on Arch use sudo pacman -S gcc.

No installation? Use an online compiler

If you cannot install anything, sites such as onlinegdb.com or godbolt.org can compile C in the browser. They require internet access, so they are only a fallback for this offline course.

Step 2 — Choose an editor

  • VS Code + the C/C++ extension — cross-platform and popular.
  • Code::Blocks or Dev-C++ — simple IDE bundles for beginners.
  • CLion — a full commercial IDE.
  • Vim, Neovim, Emacs — fast terminal editors if you prefer the keyboard.
  • Any plain text editor works. Do not use a word processor such as Word.

Step 3 — Write your first program

Create a folder called c-projects and inside it a file named hello.c:

#include <stdio.h>

int main(void) {
    printf("Hello, World!\n");
    return 0;
}
Output
Hello, World!

Step 4 — Compile and run

Open a terminal in the folder that contains hello.c.

GCC / Clang

gcc hello.c -o hello
./hello        # macOS / Linux
hello.exe      # Windows

The -o hello option names the output file. Without it, GCC writes a.out (or a.exe on Windows).

MSVC

cl hello.c
hello.exe

Useful compiler flags

FlagMeaning
-WallEnable common warnings.
-WextraEnable extra warnings.
-WerrorTreat warnings as errors.
-std=c11 / -std=c17Choose the language standard.
-gInclude debug information (for GDB).
-O2Optimise for speed.
-lmLink the maths library (needed for sqrt etc. on Linux).

The compile → link → run pipeline

  1. Preprocessing — #include and #define are expanded.
  2. Compilation — C source becomes assembly, then object code (.o / .obj).
  3. Linking — your object files are joined with libraries to make an executable.
  4. Execution — the operating system loads the program and calls main.

Common first-run problems

MessageFix
'gcc' is not recognizedGCC is not installed or its bin folder is not on PATH. Reopen the terminal after editing PATH.
stdio.h: No such file or directoryThe compiler's standard library is missing — reinstall the toolchain.
undefined reference to 'main'You compiled the wrong file, or main is misspelled.
expected ';' before ...A semicolon is missing on the previous line.
Permission denied when runningRun ./hello, not hello, on Linux/macOS, and mark it executable with chmod +x hello.

Tip: compile with gcc -Wall -Wextra -std=c17 hello.c -o hello from day one. The warnings catch real bugs.
