C Introduction

C is a general-purpose, compiled programming language created by Dennis Ritchie at Bell Labs between 1969 and 1973. It was designed for writing the Unix operating system — and it is still one of the most influential languages ever made.

What is C?

C is a procedural language: a program is a collection of functions, and execution starts at main(). It is statically typed (every variable has a type known at compile time), compiled (source code is translated to machine code before it runs) and low-level enough to work directly with memory through pointers.

Despite being small, C is powerful. The same language can write a tiny microcontroller program and a large operating system kernel.

#include <stdio.h>

int main(void) {
    printf("Hello, World!\n");
    return 0;
}
Output
Hello, World!

Why is C called a "middle-level" language?

It combines features of high-level languages (functions, loops, structured code) with low-level access (raw memory, bit operations, pointers). That combination is why C is used for both application code and system code.

Where C is used

  • Operating systems — Linux, Windows, macOS and Android kernels.
  • Embedded systems — cars, routers, washing machines, medical devices.
  • Databases — SQLite, PostgreSQL and MySQL are largely C/C++.
  • Language runtimes — CPython, Ruby MRI and the JVM are written in C/C++.
  • Tools — Git, curl, the core of most command-line utilities.
  • Libraries — OpenSSL, zlib, libpng, FFmpeg and thousands more.

What makes C different?

  • Manual memory management. You allocate memory with malloc and release it with free. Nothing happens automatically, which is both freedom and responsibility.
  • Pointers. Variables that store addresses. They enable efficient data structures and are the source of many bugs when used carelessly.
  • No classes, exceptions or garbage collector. C keeps the language small. Libraries provide the rest.
  • Undefined behaviour. Some mistakes (reading past an array, using freed memory) are not required to produce an error — the behaviour is simply undefined. Learning what not to do matters.

Your first program explained

#include <stdio.h>   // gives access to printf

int main(void) {     // execution starts here
    printf("Hello, World!\n");  // print text + newline
    return 0;        // 0 means success
}
  • #include <stdio.h> — a preprocessor directive that includes the standard input/output header.
  • int main(void) — the entry point. int is the value returned to the operating system.
  • printf(...) — prints formatted text to standard output.
  • \n — an escape sequence meaning "new line".
  • return 0; — tells the shell the program succeeded.
  • ; — ends a statement. Almost every C statement needs one.
