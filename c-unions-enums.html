C Unions & Enums

Unions and enumerations are two small but useful tools: a union lets several members share one block of memory, and an enum gives names to a fixed set of integers.

Unions

A union looks like a structure, but all members share the same storage. Its size is the size of its largest member. Writing one member overwrites the others.

#include <stdio.h>

union Value {
    int i;
    float f;
    char c;
};

int main(void) {
    union Value v;

    printf("size = %zu\n", sizeof(v));   // 4 on most systems

    v.i = 65;
    printf("as int:   %d\n", v.i);
    printf("as char:  %c\n", v.c);        // 'A' (lowest byte)
    return 0;
}
Output
size = 4
as int:   65
as char:  A

Tagged unions

Because a union does not remember which member is active, pair it with an enum tag inside a structure.

#include <stdio.h>

typedef enum { TYPE_INT, TYPE_FLOAT, TYPE_TEXT } ValueKind;

typedef struct {
    ValueKind kind;
    union {
        int i;
        float f;
        const char *s;
    } data;
} Value;

void print_value(const Value *v) {
    switch (v->kind) {
        case TYPE_INT:   printf("int: %d\n", v->data.i);   break;
        case TYPE_FLOAT: printf("float: %.2f\n", v->data.f); break;
        case TYPE_TEXT:  printf("text: %s\n", v->data.s);   break;
    }
}

int main(void) {
    Value a = { .kind = TYPE_INT,   .data.i = 42 };
    Value b = { .kind = TYPE_TEXT,  .data.s = "hello" };

    print_value(&a);
    print_value(&b);
    return 0;
}
Output
int: 42
text: hello

Enumerations

An enum declares a set of named integer constants. It makes code readable and restricts values to a known list.

#include <stdio.h>

enum Day {
    MON,     // 0
    TUE,     // 1
    WED,     // 2
    THU,     // 3
    FRI,     // 4
    SAT,     // 5
    SUN      // 6
};

int main(void) {
    enum Day today = WED;
    printf("%d\n", today);     // 2

    if (today == WED) {
        printf("Halfway through the week\n");
    }
    return 0;
}
Output
2
Halfway through the week

Custom enum values

enum Status {
    OK = 200,
    NOT_FOUND = 404,
    SERVER_ERROR = 500
};

enum Flags {
    READ    = 1 << 0,   // 1
    WRITE   = 1 << 1,   // 2
    EXECUTE = 1 << 2    // 4
};

int perms = READ | WRITE;   // 3

When you assign one value, the following names continue counting from it:

enum Example {
    A,        // 0
    B,        // 1
    C = 10,
    D,        // 11
    E         // 12
};

typedef enum

The tag is optional, but when you use one you normally also create a typedef for convenience.

typedef enum {
    LOW,
    MEDIUM,
    HIGH
} Priority;

Priority p = HIGH;

switch (p) {
    case LOW:    puts("low");    break;
    case MEDIUM: puts("medium"); break;
    case HIGH:   puts("high");   break;
}
Output
high

Enum with a switch

#include <stdio.h>

typedef enum { RED, YELLOW, GREEN } Light;

const char *action(Light light) {
    switch (light) {
        case RED:    return "Stop";
        case YELLOW: return "Prepare to stop";
        case GREEN:  return "Go";
        default:     return "Unknown";
    }
}

int main(void) {
    printf("%s\n", action(GREEN));
    return 0;
}
Output
Go

Practical notes

  • An enum's underlying type is an implementation-defined integer type large enough to hold all values.
  • Enumerators are visible in the surrounding scope (unlike struct members).
  • C does not prevent assigning an integer to an enum variable — the type is a helpful convention, not a strict guarantee.
  • Use enums for states, options, error codes and command types.
  • Do not take the address of a union member you did not last write — reading an inactive member is implementation-defined and often meaningless.

Warning: type-punning through unions (writing one member and reading another) is a common but non-portable trick. Unless your compiler documents it, avoid relying on it. Use memcpy for safe reinterpretation.
