C Syntax

C syntax is the set of rules that defines how a C program is written. It is small and consistent: statements end with semicolons, blocks are wrapped in braces, and case matters.

The smallest C program

#include <stdio.h>

int main(void) {
    printf("Hello, World!");
    return 0;
}
Output
Hello, World!

Statements and semicolons

A statement is one instruction. In C, most statements end with a semicolon:

int age = 25;
printf("Age: %d\n", age);
return 0;

Forgetting the semicolon is the most common compile error. The compiler often reports it on the next line, because that is where it notices the statement never finished.

Blocks and braces

Braces { } group statements into a block. Function bodies, loops, conditions and structures all use blocks.

int main(void) {
    int x = 10;

    if (x > 5) {
        printf("x is large\n");
        printf("still inside the if block\n");
    }

    return 0;
}

Case sensitivity

C is case-sensitive. age, Age and AGE are three different names. Keywords are always lowercase: int, not Int.

Identifiers

Identifiers are names you give to variables, functions, structures and so on. The rules:

  • May contain letters, digits and underscores.
  • Must begin with a letter or an underscore (not a digit).
  • Cannot be a keyword such as int or return.
  • Are case-sensitive.
int score = 100;        // valid
int _count = 3;         // valid
int player2 = 7;        // valid
// int 2player = 7;     // invalid: starts with a digit
// int float = 1;       // invalid: float is a keyword

Naming conventions

  • snake_case for variables and functions: total_score, read_file.
  • UPPER_CASE for macros and constants: MAX_SIZE, PI.
  • Descriptive names beat short names: student_count is clearer than n.

Whitespace and indentation

Spaces, tabs and newlines are ignored by the compiler (except inside strings and to separate tokens). Indentation is for humans, but consistent indentation makes bugs visible. Four spaces per level is a common C style.

int main(void){int x=1;if(x){printf("%d",x);}return 0;}

/* The same program, formatted: */

int main(void) {
    int x = 1;
    if (x) {
        printf("%d", x);
    }
    return 0;
}

Comments in brief

Comments start with // (to end of line) or wrap with /* ... */. They are ignored by the compiler.

// A single-line comment
printf("Hello");  // also a comment after code

/*
   A multi-line comment.
   Useful for longer explanations.
*/

Read the full Comments chapter for details.

The main function

Every C program must have exactly one main. Execution starts there. The standard forms are:

int main(void) { ... }                     // no arguments

int main(int argc, char *argv[]) { ... }   // command-line arguments

The return 0; value is passed to the operating system. Zero means success.

Preprocessor directives

Lines starting with # are handled before compilation. They do not end with a semicolon.

#include <stdio.h>
#include <stdlib.h>
#define MAX 100

int main(void) {
    printf("%d\n", MAX);
    return 0;
}
Output
100

Common syntax mistakes

MistakeExampleCorrection
Missing semicolonint x = 5int x = 5;
Assignment in a conditionif (x = 5)if (x == 5)
Using a name before declaring itprintf("%d", y);Declare y first.
Mismatched bracesif (x) { ...Close every { with }.
Wrong quotesprintf(“Hi”);Use straight quotes: "Hi".

Tip: let your editor auto-indent and auto-close braces. Compile often — small programs are much easier to debug.
