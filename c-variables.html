C Variables

A variable is a named container for a value. Every variable in C has a type that decides what kind of value it can hold and how much memory it uses.

Declaring a variable

Declaration tells the compiler the variable's name and type:

int age;        // declares an int named age
float price;    // declares a float named price
char grade;     // declares a char named grade

At this point the value is indeterminate — it contains whatever happened to be in that memory. Never read a variable before assigning it.

Assigning a value

int age;
age = 25;

printf("Age: %d\n", age);
Output
Age: 25

Initialising at declaration

You can combine declaration and assignment. This is the safest habit.

#include <stdio.h>

int main(void) {
    int age = 25;
    float height = 5.9f;
    char grade = 'A';
    double balance = 1250.75;

    printf("Age: %d\n", age);
    printf("Height: %.1f\n", height);
    printf("Grade: %c\n", grade);
    printf("Balance: %.2f\n", balance);
    return 0;
}
Output
Age: 25
Height: 5.9
Grade: A
Balance: 1250.75

Changing a variable

Assignment replaces the old value. The variable keeps its type.

#include <stdio.h>

int main(void) {
    int score = 10;
    printf("Start: %d\n", score);

    score = 25;
    printf("After: %d\n", score);

    score = score + 5;
    printf("Final: %d\n", score);
    return 0;
}
Output
Start: 10
After: 25
Final: 30

Declaring several variables at once

int x = 1, y = 2, z = 3;

// Same type, no initial value:
int a, b, c;

// Mixed types must be separate declarations:
int count = 0;
double total = 0.0;

Naming rules

  • Letters, digits and underscores only.
  • Must start with a letter or underscore.
  • Case-sensitive: total and Total differ.
  • Cannot be a C keyword.
  • Should describe the value: item_count, not ic.
int student_count = 30;
int max_score = 100;
float average_temp = 27.5f;
char middle_initial = 'K';

// int 1st_place = 1;   // error: starts with a digit
// int for = 10;        // error: keyword

Local and global variables

A variable declared inside a function is local: it exists only while that function runs. A variable declared outside every function is global: it exists for the whole program and can be used by any function.

#include <stdio.h>

int global_count = 0;      // global

void bump(void) {
    int local = 5;         // local to bump()
    global_count++;
    printf("local = %d, global = %d\n", local, global_count);
}

int main(void) {
    bump();
    bump();
    // printf("%d", local);  // error: local is not visible here
    return 0;
}
Output
local = 5, global = 1
local = 5, global = 2

Prefer local variables. Globals make it hard to see which code changes a value.

Constants

Use const when a value must not change:

const double PI = 3.14159265358979;
const int MAX_USERS = 100;

// PI = 3.14;   // compile error: PI is read-only

See the Constants chapter for #define and literal rules.

Warning: reading an uninitialised local variable is undefined behaviour. Some compilers with -Wall will warn you; always initialise.
