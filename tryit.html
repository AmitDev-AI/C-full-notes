Try It Editor

Write C code, press Run, and see real output — no internet connection, no account, and nothing sent to a server. The editor uses PicoC, a small C interpreter compiled to WebAssembly.

Want a native executable? Use Download .c, then run gcc main.c -o main and ./main (or main.exe on Windows). See Get Started for compiler installation.

About the built-in engine. PicoC is an interpreter for a practical subset of C89/C99. It supports printf, scanf, arrays, strings, pointers, structs, unions, enums, recursion, malloc, file-style I/O and most of the standard library. A few valid C features — such as aggregate initialisers for structs, very complex macros and variable-length arrays — are not supported. For full standard C, compile with GCC or Clang.

PicoC is BSD-licensed. See attribution. Runs are limited to 10 seconds; infinite loops are stopped automatically.
