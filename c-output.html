C Output

C prints output with functions from <stdio.h>. printf is the workhorse: it formats values and writes them to the screen.

printf

The name means print formatted. The first argument is a format string; the rest are the values to insert.

#include <stdio.h>

int main(void) {
    printf("Hello, World!\n");
    printf("I am learning C.\n");
    return 0;
}
Output
Hello, World!
I am learning C.

Format specifiers

A % followed by a letter is a placeholder. The matching argument replaces it.

#include <stdio.h>

int main(void) {
    int age = 25;
    float height = 5.9f;
    char grade = 'A';
    char name[] = "Amit";

    printf("Name: %s\n", name);
    printf("Age: %d\n", age);
    printf("Height: %.1f feet\n", height);
    printf("Grade: %c\n", grade);
    return 0;
}
Output
Name: Amit
Age: 25
Height: 5.9 feet
Grade: A

Printing several values

#include <stdio.h>

int main(void) {
    int x = 10, y = 20;
    printf("x = %d, y = %d, sum = %d\n", x, y, x + y);
    return 0;
}
Output
x = 10, y = 20, sum = 30

The order of the arguments must match the order of the specifiers. A mismatch such as passing a double to %d is undefined behaviour — it may print garbage or crash.

Width, precision and padding

You can control how wide a field is and how many decimal places are shown.

#include <stdio.h>

int main(void) {
    printf("%d\n", 42);
    printf("%5d\n", 42);        // width 5, right aligned
    printf("%-5d|\n", 42);      // width 5, left aligned
    printf("%05d\n", 42);       // zero padded
    printf("%.2f\n", 3.14159);  // 2 decimal places
    printf("%8.2f\n", 3.14159); // width 8, 2 decimals
    printf("%+d\n", 42);        // always show sign
    return 0;
}
Output
42
   42
42   |
00042
3.14
    3.14
+42

puts and putchar

puts prints a string followed by a newline. putchar prints one character. They are simpler and slightly faster than printf when you do not need formatting.

#include <stdio.h>

int main(void) {
    puts("Hello from puts");
    putchar('C');
    putchar('\n');
    return 0;
}
Output
Hello from puts
C

Output buffering

printf writes into a buffer that is flushed when it fills, when the program ends, or when you print a newline on a terminal. If your program crashes before flushing, some output may be lost. fflush(stdout); forces a flush.

Note: standard output is normally line-buffered on a terminal and fully buffered when redirected to a file. Errors should go to stderr with fprintf(stderr, ...).
