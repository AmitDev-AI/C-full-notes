C Comments

Comments are notes for humans. The compiler ignores them completely, so they cost nothing at run time and make code easier to understand.

Single-line comments

Start with //. Everything until the end of the line is a comment. This style was added to C in C99, but compilers supported it long before.

#include <stdio.h>

int main(void) {
    // Print a greeting
    printf("Hello, World!\n");

    int score = 100;  // current score
    printf("Score: %d\n", score);

    return 0;
}
Output
Hello, World!
Score: 100

Multi-line comments

Wrap text in /* and */. This works everywhere, including inside a line of code and in C89.

/*
   Program: greeting.c
   Author:  Amit
   Purpose: show how comments work
*/

#include <stdio.h>

int main(void) {
    printf("Hello!\n");   /* inline comment */

    /*
       This entire block
       is ignored by the compiler.
    */
    return 0;
}

What comments are for

  • Explaining why code does something, not what it does. The code already says what.
  • Documenting functions — purpose, parameters, return value.
  • Temporarily disabling code while debugging.
  • Marking work with TODO or FIXME.
  • File headers — author, date, licence.
/*
 * Returns the larger of two integers.
 * If the values are equal, returns a.
 */
int max(int a, int b) {
    return (a > b) ? a : b;
}

Comments you should avoid

// BAD: repeats the code
counter = counter + 1;  // add one to counter

// BETTER: explains intent
counter++;              // count this retry attempt

// BAD: stale comment
// returns 0 on success
return -1;              // code changed, comment did not

Can comments be nested?

No. Multi-line comments do not nest. The first */ ends the comment, even if an inner /* appeared earlier.

/* outer comment
   /* inner comment */   <-- this ends the comment
   still code? */

The text after the closing */ is parsed as C and will cause an error. Use // on each line for commenting out blocks containing multi-line comments.

Commented-out code

You can comment out code to disable it:

int main(void) {
    printf("This runs\n");

    // printf("This does not run\n");

    /*
    printf("Neither does this\n");
    printf("nor this\n");
    */
    return 0;
}

Do not leave large blocks of dead code in finished programs — use version control (Git) to keep old versions instead.

Preprocessor comments

Comments are removed before the preprocessor runs, so you cannot use them inside a #define in tricky ways. Keep macro definitions simple and comment above the line.
