C Switch

The switch statement selects one block from many options based on the value of a single integer or character expression.

Syntax

switch (expression) {
    case value1:
        statements;
        break;
    case value2:
        statements;
        break;
    default:
        statements;
        break;
}

Basic example

#include <stdio.h>

int main(void) {
    int day = 3;

    switch (day) {
        case 1:
            printf("Monday\n");
            break;
        case 2:
            printf("Tuesday\n");
            break;
        case 3:
            printf("Wednesday\n");
            break;
        case 4:
            printf("Thursday\n");
            break;
        case 5:
            printf("Friday\n");
            break;
        case 6:
            printf("Saturday\n");
            break;
        case 7:
            printf("Sunday\n");
            break;
        default:
            printf("Invalid day\n");
            break;
    }

    return 0;
}
Output
Wednesday

Why break matters

Without break, execution falls through into the next case. This is sometimes useful, but it is usually a bug.

#include <stdio.h>

int main(void) {
    int x = 1;

    switch (x) {
        case 1:
            printf("One\n");
            /* no break */
        case 2:
            printf("Two\n");
            /* no break */
        case 3:
            printf("Three\n");
            break;
        default:
            printf("Other\n");
    }

    return 0;
}
Output
One
Two
Three

Intentional fall-through can group cases. Add a comment such as /* fall through */ so readers know it is deliberate.

Grouping cases

#include <stdio.h>

int main(void) {
    char grade = 'B';

    switch (grade) {
        case 'A':
        case 'B':
        case 'C':
            printf("Pass\n");
            break;
        case 'D':
        case 'F':
            printf("Fail\n");
            break;
        default:
            printf("Invalid grade\n");
    }

    return 0;
}
Output
Pass

The default case

default runs when no case matches. It can appear anywhere, but placing it last is conventional. Although optional, including it is good practice.

Switch with characters and enums

#include <stdio.h>

enum Op { ADD, SUB, MUL };

int main(void) {
    char choice = 'm';
    enum Op op = MUL;

    switch (choice) {
        case 'a':
            printf("Add selected\n");
            break;
        case 's':
            printf("Subtract selected\n");
            break;
        default:
            printf("Unknown choice\n");
    }

    switch (op) {
        case ADD: printf("add\n"); break;
        case SUB: printf("subtract\n"); break;
        case MUL: printf("multiply\n"); break;
    }
    return 0;
}
Output
Unknown choice
multiply

Rules and limitations

  • The controlling expression must have an integer type: int, char, short, long, or enum.
  • Case labels must be constant integer expressions — no variables, no ranges, no strings.
  • Labels must be unique within one switch.
  • float, double and strings cannot be switched on.
  • Declaring variables directly after a label needs a block { }.
// Not allowed: non-constant case
int limit = 10;
switch (x) {
    case limit:   // error
        break;
}

// Not allowed: range case (use if/else instead)
switch (x) {
    case 1 ... 5:  // GNU extension, not standard C
        break;
}

switch vs if...else

Use switch whenUse if...else when
Comparing one value against several fixed constantsTesting ranges (x > 10)
Working with an enum or menu choiceCombining different variables
The options are known at compile timeComparing strings or floating-point values

Complete example: menu

#include <stdio.h>

int main(void) {
    int choice = 2;

    printf("1. Say hello\n");
    printf("2. Show a number\n");
    printf("3. Quit\n");

    switch (choice) {
        case 1:
            printf("Hello!\n");
            break;
        case 2:
            printf("The answer is 42\n");
            break;
        case 3:
            printf("Goodbye\n");
            break;
        default:
            printf("Invalid option\n");
            break;
    }

    return 0;
}
Output
1. Say hello
2. Show a number
3. Quit
The answer is 42

Warning: forgetting break after the last case can also cause trouble later when new cases are added. Some compilers warn about implicit fall-through; heed those warnings.
